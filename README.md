OneTrip is a mobile-first PWA that stops drivers from "pencil whipping" pre-trip truck inspections — it forces a live-camera, phased checklist walkthrough and backs every certified inspection up to a company-controlled Google Drive. This repository (`onetrip-driver`) is the driver-facing app itself: plain HTML/CSS/vanilla JavaScript with no build step, deployed automatically by GitHub Pages on every push to `main`. Uploads are handled by a separate companion repo, `onetrip-drive-function`, a small Node.js Cloud Run function that holds the real Drive credential so the driver never sees a Google sign-in; deploying it means pasting `index.js` into the Cloud Run console's Source tab, since it has no git-push-to-deploy pipeline of its own.
